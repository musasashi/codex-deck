# Codex Deck

Codex Deckは、ChatGPTの利用枠で複数のCodexタスクを実行するVS Code拡張機能です。拡張機能と公式Codex CLIはWSL側で動作します。

## 特徴

- タスクごとにタブを開き、会話を分岐したり、公式Codex CLIの標準OpenAIプロバイダーで作成した会話を履歴から再開したりできます。
- チャットにはMermaidの図と数式を表示できます。文章を選択して、同じ会話で引用したり、質問プリセットで別のタスクに質問したりできます。
- モデル・推論強度・速度・権限をプリセットで切り替えられます。モデルの候補はサインイン中のCodexから取得します。
- 入力欄のそばにアカウントの利用枠の残量を表示します。自動継続を予約したタスクは、上限で停止した後、利用枠の回復を確認してから再開します。

## はじめる

必要なものは **WSL・WindowsのVS Code 1.106以降とWSL拡張・WSL内の公式Codex CLI・Node.js 24以降（WSL内でのVSIX作成用）** です。

1. VS CodeからWSLに接続して、作業フォルダーを開きます。
2. WSL内に公式Codex CLIをインストールし、WSLのターミナルで`codex --version`を確認します。
3. WSL内のターミナルで、このリポジトリのルートからVSIXを作成します。

   ```sh
   npm ci
   npm run package
   ```

4. WSLに接続したVS Codeの拡張機能ビューで「VSIXからのインストール」を選び、生成された`.vsix`ファイルをWSL側にインストールします。
5. アクティビティバーの「Codex Deck」→「＋」でタスクを作成します。

WSL内の公式Codex CLIとサインイン状態を共有します。初回のサインインは、タスク右上の「•••」→「アカウント」から行えます。入力欄に `/` を入力するとコマンド一覧が開きます。`/plan` でプランモードを切り替え、`/plan 指示` で計画の作成を依頼できます。
