# Codex Deck

CodexのタスクをVS Codeのエディタタブで並行して扱う拡張機能です。別途インストールした公式Codex CLIを使用します。

## 特徴

- **複数タブ**：タスクごとにタブを開き、分割して並行作業できます。
- **プリセット**：モデル・推論強度・権限の組を保存し、ワンクリックで切り替えられます。
- **Hugging Face**：HFモデルと単価をプリセットに保存し、OpenAIのタスクと並行利用できます。タスクごとの累計費用を表示します。
- **Responses API**：接続先・認証用の環境変数・モデルを登録し、プリセットから利用できます。画像入力・推論強度・構造化出力はモデルごとに設定します。
- **自動継続予約**：使用量上限で停止した会話を、利用枠の回復後に再開します。
- **残量の常時表示**：5時間枠・週次枠の残量を入力欄のそばに表示します。

## はじめる

必要なものは **VS Code 1.96以降・公式Codex CLI・Node.js 24以降（VSIX作成用）** です。

1. 公式Codex CLIをインストールし、`codex --version`で実行できることを確認します。
2. このリポジトリのルートでVSIXを作成します。

   ```sh
   npm ci
   npm run package
   ```

3. VS Codeの拡張機能ビューで「VSIXからのインストール」を選び、生成された`.vsix`ファイルを読み込みます。
4. 作業フォルダーを開き、アクティビティバーの「Codex Deck」→「＋」でタスクを作成します。

認証とCodex設定はCLIと共有します。サインインはタスク右上の「•••」→「アカウント」から行えます。

## 対応範囲

クラウドへのタスク委任・結果取得は未対応です。利用できるコマンドは入力欄の`/`で確認できます。`/plan`でプランモードを切り替え、`/plan 指示`で計画の作成を依頼できます。
